 # TASK 1 – Payment Calculator for a Village Milk Co-operative

## Aim
To analyse the requirements of the Ksheera Village Milk Co-operative payment calculator and identify the inputs, outputs, and payment rules.

## Problem Statement
The milk co-operative needs a Python program to calculate the payment due to farmers based on the quantity of milk supplied, fat percentage, and Solid-Not-Fat (SNF) percentage.

## Inputs
- Quantity of milk in litres
- Fat percentage
- SNF percentage
- Applicable base rate per litre

## Processing
1. Read the milk quantity, fat percentage, and SNF percentage.
2. Compare the fat and SNF values with the reference values.
3. Calculate the rate per litre using the adjustment rules given in the assignment.
4. Multiply the rate per litre by the quantity of milk.
5. Display the calculated rate and total payment.

## Outputs
- Calculated rate per litre
- Total payment to the farmer

## Example
For 10 litres of milk at the reference values of 3.5% fat and 8.5% SNF:

Base rate = ₹30.00 per litre

Total payment = 10 × ₹30.00 = ₹300.00

## Conclusion
The analysis identifies the basic inputs, processing steps, and outputs required for the milk payment calculator. The implementation and testing must follow the complete assignment specifications.
