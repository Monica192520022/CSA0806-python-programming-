# TASK 3 – Constants in Python

## Aim
To define and use constants for the milk payment calculator.

## Explanation
Constants store values that should remain fixed throughout a program. Python does not enforce constants, so uppercase names are commonly used to indicate that a value should not be changed.

## Constants Used
- `BASE_RATE`: ₹30.00 per litre
- `REFERENCE_FAT`: 3.5%
- `REFERENCE_SNF`: 8.5%
- `FAT_ADJUSTMENT`: ₹0.40 per 0.1% fat change
- `SNF_ADJUSTMENT`: ₹0.30 per 0.1% SNF change

## Procedure
1. Define the constants at the beginning of the program.
2. Display their values.
3. Run the program in a Python compiler.
4. Verify that the displayed values match the definitions.

## Result
Record the actual output after running `task3.py`.

## Conclusion
Using named constants makes a program easier to read and maintain. If an approved payment rule changes, its constant can be updated in one place.
